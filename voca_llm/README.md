# Voca LLM

An offline large language model for Home Assistant Assist, running on the CPU (made for a Raspberry Pi 5 with 8 GB):
[llama.cpp](https://github.com/ggml-org/llama.cpp) with **Qwen3-4B-Instruct-2507** (or the faster Qwen3-1.7B).

Speaks the Ollama API, so it plugs into Home Assistant's built-in **Ollama** integration as a conversation agent
that can control your devices. See the **Documentation** tab for setup.
