# Voca Speech

Local German/English speech for Home Assistant Assist, on the CPU:

- **Text-to-speech:** tiny-voca (64 voices, German + English) and apptor-tiny-tts (2 German voices)
- **Speech-to-text:** Phonon-2.5

Shows up automatically as a Wyoming device. Also serves an OpenAI-compatible API on port 8000.
See the **Documentation** tab for setup.
